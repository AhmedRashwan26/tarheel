# 🚗 ترحيل (Tarheel) - الباك اند الإنتاجي لمنصة نقل وتوصيل الركاب المجدول

نظام خلفي (Backend) إنتاجي متكامل، عالي الأداء والاستقرار، مبني بأحدث المعايير الهندسية باستخدام **NestJS** و **TypeScript** و **Prisma ORM** و **PostgreSQL** و **Redis** و **WebSockets**.

---

## 🌟 نظرة عامة على المشروع وأقسام المنصة

منصة **"ترحيل"** مقسمة إلى قسمين رئيسيين مع نظام مراسلة داخلي محمي ومركزي خدمة العملاء والدعم الفني:

### 1. 👥 قسم العملاء (Clients)
- **التسجيل والمصادقة المرنة**: إمكانية التسجيل والتحقق إما **برقم الجوال** أو **بالبريد الإلكتروني** (رمز OTP).
- **نشر طلبات المشاوير**:
  - تحديد نقطة الانطلاق والوصول (الإحداثيات والعنوان).
  - تحديد وقت الذهاب المفضل.
  - خيار تحديد وجود عودة (`hasReturn`) وتحديد وقت العودة بدقة (`returnTime`).
  - تحديد نوع التكرار: مشوار لمرة واحدة، أسبوعي، شهري، أو أيام محددة.
  - تحديد عدد الركاب والملاحظات الإضافية.
- **استقبال ومقارنة عروض الأسعار**: استعراض عروض السائقين، تقييماتهم، وتفاصيل سياراتهم وصورها.
- **نظام الضمان المالي والضريبة (Tarheel Escrow & 15% VAT)**:
  - عند قبول العرض ينتقل العميل لصفحة الدفع الإلكتروني (مدى، بطاقات ائتمانية، Apple Pay، STC Pay).
  - **احتساب 15% ضريبة القيمة المضافة**: تضاف 15% على سعر العرض الأساسي وتدفع بالكامل لحساب الضمان.
  - **تنبيه أمني صارم**: حظر التعامل النقدي المباشر أو التحويل البنكي للسائق.
- **التقييم وإنهاء الخدمة**: تقييم السائق عند نهاية مدة التوصيل الدورية (أسبوعية أو شهرية).

---

### 2. 🚖 قسم السائقين (Drivers)
- **التسجيل والتحقق الصارم (KYC)**:
  - **إجبارياً برقم الهاتف** (لا يقبل التسجيل بالإيميل للسائقين).
  - رقم الهوية الوطنية / الإقامة، ورخصة القيادة ورخصة سير السيارة (الاستمارة).
  - مواصفات السيارة: الماركة، الموديل، سنة الصنع، رقم اللوحة، عدد المقاعد، وتكييف السيارة.
  - **رفع صور السيارة من الاتجاهات الأربعة** (أمام، خلف، يمين، يسار) + صورة داخلية.
  - **بيانات الحساب البنكي وإثبات الحساب (PDF)**:
    - اسم البنك، رقم الآيبان (`IBAN`)، اسم صاحب الحساب، وشهادة الآيبان الرسمية (ملف PDF).
- **الإقرار والشروط**:
  - الإقرار باقتطاع **عمولة 10%** فقط للتطبيق، ومنع استلام أي مبالغ نقدية.
- **المحفظة والتحويل البنكي المباشر**:
  - فور انتهاء مدة التوصيل الدورية وتقييم العميل للسائق: يتم خصم 10% عمولة ترحيل **وتحويل صافي المستحقات (90%) مباشرة إلى الحساب البنكي المسجل للسائق**.

---

### 3. 💬 التواصل الداخلي الآمن ومشاركة المواقع (In-App Chat, Voice & Location)
- التواصل بين العميل والسائق يتم **حصرياً عبر التطبيق** لضمان الحقوق وتوثيق الاتفاقيات وتجنب المعاملات الخارجة عن ضمان ترحيل.
- يدعم النظام:
  - **الرسائل النصية الفورية (Instant Text Messages)**.
  - **الرسائل والتسجيلات الصوتية (Voice Notes)** مع تحديد المدة الزمنية بالثواني.
  - **مشاركة الموقع الجغرافي الحي (Live GPS Location Sharing)** بالإحداثيات الدقيقة واسم الموقع ليسهل التقاء السائق والراكب عند نقطة الانطلاق.
  - **الصور والمرفقات**.
- بث مباشر للرسائل اللحظية وتحديثات الموقع عبر **WebSockets (Socket.io)**.

---

### 4. 🎧 صفحة خدمة العملاء (Customer Service)
- مخصصة للاستفسارات العامة، الاستعلام عن العقود، تعديل الرحلات، والاستفسارات المالية والمدفوعات.
- نظام تذاكر ومحادثات متابعة مع فريق خدمة العملاء (`TicketDepartment: CUSTOMER_SERVICE`).

---

### 5. 🛠️ صفحة الدعم الفني (Technical Support)
- مخصصة للمشاكل التقنية، أخطاء التطبيق (Bugs)، مشاكل بوابات الدفع، الخرائط والمواقع، ومشاكل التسجيل الصوتي.
- تسجيل تلقائي لإصدار التطبيق (`appVersion`)، معلومات نظام التشغيل والجهاز (`deviceInfo`)، وإرفاق لقطات الشاشة (`attachments`).

## 📋 أهم نقاط الاتصال البرمجية (API Endpoints)

### 💬 المحادثات والتواصل ومشاركة الموقع (`/api/v1/chat`)
- `POST /api/v1/chat/send`: إرسال رسالة نصية، رسالة صوتية (Voice Note)، أو موقع جغرافي (`LOCATION` مع `latitude`, `longitude`, `locationAddress`).
- `GET /api/v1/chat/contract/:contractId`: استرجاع سجل محادثة عقد معين بالكامل شاملاً المواقع والتسجيلات الصوتية.
- `GET /api/v1/chat/trip/:tripRequestId`: استرجاع محادثة طلب المشوار المفتوح.

### 🎧 خدمة العملاء والدعم الفني (`/api/v1/support`)
- `POST /api/v1/support/ticket`: فتح تذكرة جديدة (خدمة عملاء أو دعم فني).
- `GET /api/v1/support/my-tickets`: استعراض تذاكر المستخدم ومتابعة حالتها.
- `GET /api/v1/support/tickets/:id`: استعراض تفاصيل التذكرة ومحادثة الردود.
- `POST /api/v1/support/tickets/:id/reply`: إضافة رد على التذكرة.
- `GET /api/v1/support/admin/tickets`: لوحة إدارة التذاكر لفريق الدعم والإدارة.
- `PATCH /api/v1/support/admin/tickets/:id/status`: تحديث حالة التذكرة (OPEN, IN_PROGRESS, RESOLVED, CLOSED).

## 🚀 دليل التشغيل السريع (Quick Start)

```bash
# تثبيت وتوليد قاعدة البيانات
npm install
npm run prisma:generate
npm run prisma:push
npm run prisma:seed

# تشغيل خادم التطوير
npm run start:dev
```

واجهة التوثيق التفاعلية (Swagger API): **`http://localhost:3000/api/docs`**
